# Página Web da Turma

Landing page desenvolvida para apresentação da turma, contendo informações sobre alunos, professores e disciplinas.

## Estrutura do projeto

```
/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos da página
├── js/
│   └── main.js         # Scripts da página
├── assets/
│   └── img/            # Imagens utilizadas
├── politica-commits.md # Política de commits do projeto
└── README.md
```

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador, ou utilize a extensão **Live Server** no VS Code.
