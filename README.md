# Site de Apresentação da Turma de Engenharia de Software 2026.2

Este projeto consiste em uma página web interativa desenvolvida para apresentar a nossa turma

## Sobre o Projeto

O objetivo principal desta aplicação é centralizar as informações da turma em um ambiente acessível, moderno e com design responsivo. Através desta página, é possível conhecer os integrantes

## Funcionalidades

- **Apresentação Geral:** Visão geral e nome da turma.
- **Corpo Docente:** Seção dedicada aos professores da turma.
- **Lista de Alunos:** Espaço com os integrantes e perfis.
- **Contatos e Rodapé:** Links para redes, e-mails e informações de contato.
- **Design Responsivo:** Adaptado para navegação em computadores, tablets e smartphones.

## Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript
- **Gestão e Organização:** Trello (Metodologia Kanban)
- **Controle de Versão:** Git & GitHub


## Gestão do Projeto (Evolução do Kanban)

Para organizar o fluxo de trabalho e garantir o cumprimento das etapas de desenvolvimento, utilizamos a metodologia **Kanban** no Trello. As tarefas foram categorizadas desde a etapa inicial de planejamento (Backlog) até a conclusão final.

### Mapeamento das Tarefas (Backlog)

- **BK-01:** Configuração do repositório e ambiente de desenvolvimento
- **BK-02:** Prototipagem e desenvolvimento da interface visual
- **BK-03:** Nome da turma
- **BK-04:** Apresentação da turma
- **BK-05:** Lista de alunos
- **BK-06:** Professores
- **BK-07:** Disciplinas
- **BK-08:** Contatos e rodapé
- **BK-09:** Adaptação e design responsivo
- **BK-10:** Realização de testes e validação
- **BK-11:** Publicação (deploy) e registro da documentação final

### Evolução do Quadro Kanban

#### 1. Fase Inicial — Planejamento e Organização
No início do projeto, todas as tarefas foram mapeadas e organizadas na coluna de **Backlog** e **A Fazer**.

## Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/gustavosnow/Pagina-Web-Turma.git
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd Pagina-Web-Turma
   ```

3. **Abra a página no navegador:**
   - Basta dar um duplo clique no arquivo `index.html` ou abrir utilizando a extensão *Live Server* no VS Code.
